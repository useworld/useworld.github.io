    요약

    Cursor는 2026-11-13 외부 업체에 발급한 키 노출이 내부 SaaS 접근과 확장 배포 캐시 변조로 이어졌다고 밝혔다. 공격자는 2026-10-29 캐시에 악성 Anthropic.claude-code 2.1.312·2.1.313을 배치했다. 악성 빌드는 호스트 정보를 전송하고 SSH backdoor와 지속성 설치를 시도했다.

    잠재적 배포 대상은 최대 5,000명이다. 악성 빌드를 받았을 가능성이 있는 사용자 수이며, SSH 접속 성공이나 호스트 장악 건수를 뜻하지 않는다.

    확장 삭제 후에도 지속성이 남는다

    악성 확장은 독립 실행 스크립트를 남긴다. 확장 삭제와 별도로 SSH 키, LaunchAgent, 예약 작업, 시작 프로그램과 터널 프로세스를 제거해야 한다.

    타임라인

    날짜 사건
    2026-10-29 약 02:27~13:35 PT에 악성 확장이 배포됐다. 탐지 후 악성 빌드를 제거하고 마켓플레이스를 일시 중단했다. 최초 advisory의 표기 게시일이다.
    2026-10-30 IOC와 영향 버전 설명을 갱신했다. 후속 공지에 따르면 사용자와 팀 관리자 통지도 이날 시작됐다.
    2026-11-01 Cursor가 관측한 마지막 공격자 활동을 차단했다.
    2026-11-13 키 노출부터 캐시 변조까지의 조사 결과를 공개했다.

    침해 경로

    Cursor의 조사에 따르면 공격자는 Fireworks에서 노출된 접근 키로 공유용 읽기 전용 버킷의 데이터를 복사했다. 버킷에는 주로 2025년에 생성된 비 Privacy Mode 세션의 coding agent trace가 있었다.

    일부 trace에 남은 자격증명이 SaaS 접근의 발판이 됐다. 접근 대상에는 보관된 비운영 소스 저장소, 일부 지원 데이터와 이메일, 연락처와 사용 지표, agent 대화 요약, 사용자가 지원팀에 전달한 자격증명이 포함됐다. 공격자는 내부 데이터에서 얻은 자격증명으로 확장 배포 캐시에 악성 패키지를 직접 배치했다.

    변조 지점은 Cursor의 배포 캐시였다. Cursor는 Open VSX에는 악성 패키지가 없었고, Anthropic이 배포한 빌드도 아니라고 밝혔다.

    영향 범위

    대상 Cursor가 공개한 범위
    악성 확장 Windows·macOS용 Anthropic.claude-code 2.1.312·2.1.313
    잠재적 배포 노출 시간에 특정 캐시 버전을 요청한 최대 5,000명
    과거 agent trace 비 Privacy Mode 사용자 중 0.05% 미만
    API 자격증명 고객 중 0.01% 미만

    Cursor는 Privacy Mode의 프롬프트와 코드, 고객 코드 저장소, 현재 트래픽, 공식 앱과 업데이트는 영향받지 않았다고 밝혔다. 릴리스 서명 키도 노출되지 않았다는 설명이다.

    악성 확장의 동작

    변조된 extension.js는 호스트명, 사용자명, OS, 아키텍처, 홈·작업 디렉터리, Git 이메일, 공인 IP와 환경변수 이름을 수집했다.

    공격자 SSH 키 추가, SSH 서비스 활성화, reverse SSH tunnel 생성이 이어졌다. macOS에서는 LaunchAgent, Windows에서는 SYSTEM 권한 예약 작업과 시작 프로그램 fallback으로 지속성을 시도했다. 터널 재시도 간격은 약 60초였다.

    Cursor는 일반 권한 환경에서 관리자 권한 요구와 코드 오류로 SSH 접속 단계가 실패한다고 설명했다. SSH 키, 지속성 파일과 정보 전송 흔적은 별도로 남을 수 있다.

    코드 분석

    출처: Cursor 악성 확장 보안 공지

    $files = "$HOME\.ssh\authorized_keys", "C:\ProgramData\ssh\administrators_authorized_keys" | Where-Object { Test-Path $_ }
if ($files -and (Select-String svc-telemetry $files)) { "svc-telemetry key found" } else { "No key found; machine not impacted" }

    현재 사용자와 관리자용 SSH 키 파일에서 공격자 키의 주석인 svc-telemetry를 찾는다. 음성 결과는 두 파일에 해당 문자열이 없다는 뜻이다. 출력 문구만으로 다른 지속성 파일이나 과거 실행까지 배제할 수는 없다.

    탐지와 대응

    네트워크

    • 134[.]209[.]82[.]225 방향 TCP 22 연결
    • 같은 IP의 TCP 8099, /beacon 대상 HTTP POST
    • 루프백 127.0.0.1:8099/beacon 대상 POST 시도

    ifconfig[.]me, api[.]ipify[.]org는 정상 공인 IP 조회 서비스다. 접근 기록은 확장 실행과 공격자 IP 통신에 연결해 판단한다.

    엔드포인트

    관측 지점 흔적
    extension.js 134[.]209[.]82[.]225, svc-telemetry
    SSH 키 authorized_keys의 svc-telemetry
    macOS ~/Library/LaunchAgents/com.apple.sysmond.plist, ~/.config/.smt, ~/.config/.smtk
    Windows 예약 작업 SysMon, %USERPROFILE%\.config\smt.cmd, 시작 프로그램의 sysmon.cmd

    영향 버전 설치 이력을 확인하고 payload 실행이나 backdoor 설치 흔적이 있는 호스트를 격리한다. 공식 remediation 스크립트로 키·지속성·터널 프로세스를 제거하고 재구축 필요성을 평가한다. 접근 가능했던 자격증명과 세션은 신뢰할 수 있는 시스템에서 교체한다.

    Cursor는 공격자 서버를 중단시켰다고 밝혔다. 로컬 지속성 파일은 별도로 제거해야 한다.
